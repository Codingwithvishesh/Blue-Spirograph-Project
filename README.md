# 🌌 Cinematic Slow-Motion Neon Blue Spirograph

An ultra-smooth, **slow-motion geometric drawing visualizer** built with **Python (Pygame)**. 

---

## 🌟 Key Features
- **Continuous Interpolated Drawing (LERP):** Har ek line instant aane ki jagah Point A se Point B tak smoothly travel karti hui dikhti hai.
- **Cinematic Tracer Bead:** Glowing neon tip line ke aage chalta hai, bilkul ek laser pen ki tarah.
- **Pure Cyan / Deep Blue Aesthetic:** Neon cyan color grading with multi-layer glow rendering.
- **Post-Draw 60 FPS Rotation:** Saari lines complete hone ke baad pura structure smoothly ghoomne lagta hai.

---

## 🚀 Quick Setup

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
2. **Run project:**
   ```bash
   python main.py
   ```

---

## 🎮 Controls

| Key | Action |
| :--- | :--- |
| `SPACE` | Pause / Play animation |
| `UP ARROW` | Line draw speed fast karein |
| `DOWN ARROW` | Line draw speed aur slow karein |
| `R` | Reset to start |
| `ESC / Close` | Exit window |
